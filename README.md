# Stonks-DataBase
A group project that implements a database to a previous project about stocks designed by me and a few others.
Since we changed our database to Supabase which is a cloud database server, I will add the link to it here

# To run this program:

1. Install dependencies for Python backend: `yfinance`, `requests`, `pandas`, `uuid`, `sqlalchemy`, `bs4`, `flask`, `supabase`, `os`, `dotenv`
2. Activate the backend by running `python testStockAPI.py` 
3. Run `npm install` in React directory to install base dependencies
4. Then, get npm packages: `react-boot`, `react-router-dom`, and `recharts`.
5. Run frontend environment by typing `npm run dev` in React directory
